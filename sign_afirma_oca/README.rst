Use Cases / Context
===================

With the current definition of Odoo, we cannot set the authentication
using a certificate, as that would depend on the inverseproxy.

Only option we have right now is to use external libraries to do that.

In Spain, FNMT is providing an standard solution enabled for all
companies. We intend to use it.
